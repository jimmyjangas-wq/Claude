# Learn to Invest

A small Streamlit web app that teaches good investing habits — built
especially for someone getting started young. It focuses on the things that
actually build wealth (time, consistency, diversification) instead of trying
to predict hot stocks, which nobody can reliably do.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Open the URL Streamlit prints (usually http://localhost:8501).

## What's inside

- **Lessons** — eight short, plain-language lessons: what a stock is, compound
  growth, index funds, diversification, dollar-cost averaging, risk, spotting
  scams, and how a minor can actually start (a custodial account).
- **Growth calculator** — enter a starting amount, a monthly contribution, a
  number of years, and an assumed return; see the projected account value and
  how much of it is compound growth versus money you put in.
- **Start early** — compares investing the same monthly amount starting now
  versus waiting until 25, to show the value of a head start.
- **Quiz** — five questions to check that the core habits stuck.

## Notes

Calculator results are estimates, not promises — real returns vary year to
year and are never guaranteed.

Educational use only. This is not financial advice. Anyone under 18 should
talk to a parent or guardian before investing real money.
